# Portfolio: HTML, CSS and JavaScript

Pages: index, work, capabilities, about, contact. No build step.

- **Run:** open `index.html`, or serve the folder (`npx serve .`).
- **Your photo:** save it as `assets/profile.jpg` (portrait, about 3:4). Optional: `assets/resume.pdf`.
- **Edit content:** the `DATA` object at the top of `js/main.js` (projects, skills, process, timeline).
- **Backend:** set `API_BASE` at the top of `js/main.js` (for example `http://localhost:5000/api`) to load projects from the Express/MongoDB API and save contact messages there. Leave it empty to run fully static.
- **Animations:** headline reveal, typewriter, count-up stats, scroll reveals, card tilt, cursor glow, page fade, marquee, rotating ring. All switch off for visitors who prefer reduced motion.
