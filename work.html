Case study 01 · 04/2026 – 08/2026

Tradewell: a live paper-trading platform

Challenge
Keep prices for 1,500+ stocks fresh for 100+ simultaneous users without making the interface feel slow.
Approach
Integrated the Upstox REST API and parsed its JSON every 7 seconds. Managed UI state with Redux and built reusable React components for responsive dashboards, candlestick charts and watchlists.
Result
Chart load time down 75% (8 s to under 2 s) through rendering optimizations and data caching. Also fixed a double-charge concurrency bug and closed 3 security vulnerabilities through systematic debugging and testing.

Case study 02 · 12/2025 – 04/2026

TripStay: a map-first property listing platform

Challenge
Keep a map with many listings smooth to pan and zoom, and keep owners able to manage their own properties.
Approach
Built the full stack app with Node.js, Express and MongoDB, with EJS and Bootstrap on the front. Integrated Mapbox location search and Cloudinary image uploads, and designed a custom marker-clustering algorithm.
Result
Smooth map interaction on dense datasets. Diagnosed and fixed a production bug that blocked owners from editing listings, then added input validation and error handling.
